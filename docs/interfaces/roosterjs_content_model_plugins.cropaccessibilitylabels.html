Optional instructions

instructions: string
  • Defined in roosterjs-content-model-plugins/lib/imageEdit/types/CropAccessibilityLabels.ts:23

Optional localized keyboard cropping instructions. No instructions are added when omitted or empty. Arrow keys move one pixel in screen directions; Tab visits top left, bottom right, then the whole image. Enter applies the crop and Escape cancels it.

Optional moveCropLabel

moveCropLabel: string
  • Defined in roosterjs-content-model-plugins/lib/imageEdit/types/CropAccessibilityLabels.ts:15

Optional accessible label for the whole-image focus target that moves the crop viewport. Falls back to "Move Crop" when omitted or empty.
